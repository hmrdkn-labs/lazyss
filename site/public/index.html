How it works Install GitHub

A terminal cockpit for your SSH and SSM hosts.

See which hosts answer, and over which access method, from one screen.

Install with Homebrew

See every host’s reach at once

Each host shows whether it answers, and over which access method: SSH, or AWS Systems Manager (SSM). Press g to check the selected host and G to check every visible host. Each row updates as its result arrives.

An SSH check runs ssh -G, then makes one TCP connection that gives up after three seconds. Up means the port accepted it, not that you can log in. An SSM check makes no new call: it reports the SSM agent’s ping status from the last inventory load. The recording above is SSH only.

At most eight checks run at once.

Your credentials stay where they are

lazyss does not read or keep your AWS credentials. For AWS hosts it asks AWS for inventory through the AWS SDK, which finds your credentials the standard way.

Its own state file holds the profile and region you chose, your pins, notes and tags, and the history of checks and sessions. It never stores AWS credentials, the SSO cache or private keys.

Cleanup shows you the change first

lazyss reads your SSH config and does not edit it, except in cleanup with --write. Cleanup is a dry run: lazyss ssh cleanup prints a plan and changes nothing. Add --check and it also tries a TCP connection to each host.

Pass --write with --host and a name, and lazyss first saves a backup beside the config, named with .lazyss-backup and a timestamp. It writes only duplicate targets, and refuses protected identities such as github.com.

Install

The Homebrew formula is the primary install path on macOS and Linux.

brew install --formula hmrdkn-labs/tap/lazyss

Or download the archive for your system from the v0.2.0 release. Each release includes checksums.txt: verify the archive against it, then put lazyss on your PATH.
