lazyssLazy Secure Shell

A terminal cockpit for your SSH and SSM hosts.

lazyss shows which hosts answer, over which access method, from one screen. Cleanup is a dry run unless you pass --write.

Install with Homebrew

brew install --formula hmrdkn-labs/tap/lazyss

Or download a release archive; each release ships with checksums.txt. Release notes for v0.2.0.

10The sweep

Press G and lazyss checks every visible host. A line prints as its check finishes. Tap or point at a line, or tab to it, to see when its result came back.

20What it checks

Each host shows whether it answers, and over which access method: SSH, or AWS Systems Manager (SSM). Press g to check the selected host. Press G to check every visible host; each row updates as its result arrives.

A sweep is bounded: at most eight checks run at once, and each connection attempt gives up after three seconds.

An SSH check is one TCP connection to the host’s SSH port, closed at once. Up means the port accepted it, not that you can log in. An SSM check makes no new call: it reports the SSM agent’s ping status from the last inventory load. The recording above is SSH only.

30What it reads

It reads your SSH config and does not edit it, except in cleanup with --write. For AWS hosts it asks AWS for inventory through the AWS SDK, which finds your credentials the standard way; lazyss does not read or keep them.

Its own state file holds the profile and region you chose, your pins, notes and tags, and the history of checks and sessions. It never stores AWS credentials, the SSO cache or private keys.

40Cleanup

Cleanup is a dry run. lazyss ssh cleanup prints a plan and changes nothing; add --check and it also tries a TCP connection to each host.

Pass --write with --host and a name, and lazyss first saves a backup beside the config, named with .lazyss-backup and a timestamp. It writes only duplicate targets, and refuses protected identities such as github.com.

50Install

The Homebrew formula is the primary install path on macOS and Linux. The command is at the top of this page.

Or download the archive for your system from the v0.2.0 release. Each release includes checksums.txt: verify the archive against it, then put lazyss on your PATH.
